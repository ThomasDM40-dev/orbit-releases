API, terminal et agents IA

Orbit peut être piloté sans ouvrir sa fenêtre : depuis tes scripts, depuis le terminal avec la commande orbit, ou par un agent IA (Claude, Cursor…) grâce au serveur MCP. Les outils lancés ainsi sont les mêmes que dans l'app : mêmes moteurs, mêmes réglages, même file GPU, et ils apparaissent dans le Centre de tâches.

Activer l'API

Paramètres › API & intégrations › Activer l'API locale. Elle est désactivée par défaut.

  • Elle n'écoute que sur ce PC : http://127.0.0.1:47821/v1 (le port se change dans la même page).
  • Chaque requête doit porter le jeton d'accès : Authorization: Bearer orb_…. Tu peux le copier ou le régénérer dans la même page.
  • Les pages web ne peuvent pas appeler l'API : toute requête venue d'un navigateur est refusée.
  • Si Orbit est fermé, la commande orbit et le serveur MCP le relancent tout seuls.

Le jeton donne accès à tes outils et à ton Drive. Ne le colle jamais dans un site ou un dépôt public.

La commande orbit

Paramètres › API & intégrations › Commande « orbit » › Installer, puis ouvre un nouveau terminal. Il n'y a rien d'autre à installer (pas de Node.js) : la commande utilise Orbit lui-même.

orbit dl https://youtu.be/… --format MP3        télécharge (BEST, 1080p, 4K… ou MP3, FLAC…)
orbit convert vacances.mov --to mp4               convertit (vidéo, audio, image, document, 3D, police, LUT)
orbit stems chanson.mp3 --stems 4                 sépare en pistes (Premium)
orbit transcribe interview.mp4 --formats srt,vtt  sous-titres (Premium)
orbit tts "Bonjour !" --voice ff_siwis            voix IA (Premium)
orbit image "un phare au coucher du soleil"       image IA (Premium)
orbit upscale vieux-clip.mp4 --scale 2            amélioration IA (Premium)

orbit tools                 liste des outils      orbit tools convert   paramètres d'un outil
orbit run <outil> --param valeur …                n'importe quel outil
orbit jobs · orbit job <id> --follow · orbit cancel <id>
orbit drive ls · orbit drive upload photo.jpg --share · orbit drive share <id> --days 7

Plusieurs fichiers ou liens d'un coup lancent un job chacun : orbit convert *.mov --to mp4, orbit dl lien1 lien2 --format MP3. Une barre de progression s'affiche pendant le travail. Ctrl+C annule le job. --json sort le résultat en JSON (pratique dans un script), et --no-wait rend l'id du job tout de suite sans attendre la fin.

Codes de sortie : 0 réussi · 1 l'outil a échoué · 2 paramètre invalide · 3 Orbit injoignable · 130 annulé.

Agents IA (MCP)

Le serveur MCP donne les outils d'Orbit à ton agent. Tu peux alors lui demander, par exemple : « télécharge cette vidéo, sépare la voix de la musique et mets la voix sur mon Drive ».

  • Claude Desktop, Cursor et autres clients MCP : Copier la config, puis colle le bloc dans la section mcpServers de la configuration du client.
  • Claude Code : Copier la commande, puis lance-la une fois dans un terminal.

Chaque outil d'Orbit devient un outil MCP (orbit_download, orbit_convert, orbit_tts…). S'y ajoutent orbit_status, orbit_job_status, orbit_cancel_job, orbit_list_jobs, orbit_analyze_url et les outils Drive (orbit_drive_list, orbit_drive_share, orbit_drive_create_folder, orbit_drive_trash). Si un travail dure plus de ~50 s, l'agent reçoit un jobId et suit la suite avec orbit_job_status.

ShareX

Paramètres › API & intégrations › ShareX › Copier, puis dans ShareX : Destinations › Uploaders personnalisés › Importer › Depuis le presse-papiers. Tes captures partent sur Orbit Drive, chiffrées, et le lien de partage est copié tout seul. Orbit Drive doit être connecté (mode Cloud) et déverrouillé dans l'app.

L'API HTTP

Toutes les réponses sont en JSON. Une erreur a toujours la même forme :

{ "error": { "code": "VALIDATION_ERROR", "message": "Paramètres invalides.", "details": [{ "field": "target", "message": "obligatoire" }] } }
Code HTTP Sens
UNAUTHORIZED 401 Jeton absent ou faux
FORBIDDEN 403 Requête venue d'un navigateur, ou hôte refusé
PREMIUM_REQUIRED 403 Outil réservé à Orbit Premium
NOT_FOUND 404 Route, outil ou job inconnu
CONFLICT / NOT_CANCELLABLE 409 Job déjà fini / outil qu'on ne peut pas interrompre
DRIVE_NOT_READY / DRIVE_LOCKED 409 Drive pas connecté / pas déverrouillé
VALIDATION_ERROR 422 Paramètre manquant, inconnu, mal typé, fichier introuvable
RATE_LIMITED 429 Trop d'essais avec un mauvais jeton (1 min d'attente)

Routes

Méthode Route Rôle
GET /v1/health Orbit répond ? (sans jeton)
GET /v1/info Version, Premium, état du Drive, outils
GET /v1/tools · /v1/tools/{id} Outils et leur schéma JSON de paramètres
POST /v1/jobs Lance un outil : { "tool": "convert", "input": { … } } → 202 + le job
GET /v1/jobs Derniers jobs (?status=running&limit=20)
GET /v1/jobs/{id} État d'un job ; ?wait=25 attend sa fin (30 s max)
GET /v1/jobs/{id}/events Flux temps réel (Server-Sent Events) : job, progress, log, end
DELETE /v1/jobs/{id} Annule le job
POST /v1/analyze Infos d'un lien sans le télécharger : { "url": "…" }
GET /v1/drive Connexion et verrou du Drive
GET /v1/drive/nodes Contenu d'un dossier (?parent=<id>, ?q=nom, ?page=, ?pageSize=)
POST /v1/drive/folders Crée un dossier : { "name": "…", "parent": "<id>" }
POST /v1/drive/files Envoi brut d'un fichier : ?name=capture.png&parent=<id>&share=1
POST /v1/drive/shares Lien de partage : { "id": "…", "days": 7, "password": "…" }
DELETE /v1/drive/nodes/{id} Met à la corbeille (30 jours)

Un job passe par queued (en attente d'un créneau GPU), running, puis succeeded, failed ou cancelled. Les chemins de fichiers sont absolus et se trouvent sur ce PC.

Outils

Outil Rôle Premium

audio op : stems, denoise, normalize, extract stems seulement

upscale Upscale, interpolation, restauration oui

image-generate Image IA locale (SDXL, FLUX Klein) oui
tts Voix IA oui

image-to-3d Image → modèle 3D (.glb) oui
pbr Photo → matériau PBR oui
drive-upload Fichiers / dossiers → Orbit Drive —

orbit tools <outil> ou GET /v1/tools/<outil> donnent la liste complète des paramètres de chaque outil.

Exemple (PowerShell)

$cfg = Get-Content "$env:USERPROFILE\.orbit\api.json" | ConvertFrom-Json
$h = @{ Authorization = "Bearer $($cfg.token)" }
$job = Invoke-RestMethod -Method Post -Uri "http://127.0.0.1:$($cfg.port)/v1/jobs" -Headers $h -ContentType 'application/json' `
  -Body '{"tool":"convert","input":{"inputPath":"C:\\Videos\\clip.mov","target":"mp4"}}'
do { $job = Invoke-RestMethod -Uri "http://127.0.0.1:$($cfg.port)/v1/jobs/$($job.id)?wait=25" -Headers $h } while ($job.status -in 'queued','running')
$job.result.outputPath

Bon à savoir

  • Les outils IA passent par la même file GPU que les onglets : un job API attend son tour si un rendu tourne déjà (réglage Jobs IA simultanés dans IA & Performance).
  • Le Drive passe par l'app, qui fait le chiffrement : ton Drive reste chiffré de bout en bout, et le jeton ne quitte jamais ton PC.
  • La liste des jobs est gardée en mémoire jusqu'à la fermeture d'Orbit (200 derniers).
