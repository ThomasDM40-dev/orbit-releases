API, terminal and AI agents

Orbit can be driven without opening its window: from your scripts, from the terminal with the orbit command, or by an AI agent (Claude, Cursor…) through its MCP server. Tools started this way are the same as in the app: same engines, same settings, same GPU queue, and they show up in the Task center.

Turn on the API

Settings › API & integrations › Enable the local API. It is off by default.

  • It only listens on this PC: http://127.0.0.1:47821/v1 (the port can be changed on the same page).
  • Every request must carry the access token: Authorization: Bearer orb_…. You can copy or regenerate it on the same page.
  • Web pages can't call the API: any request coming from a browser is refused.
  • If Orbit is closed, the orbit command and the MCP server start it for you.

The token gives access to your tools and your Drive. Never paste it into a website or a public repository.

The orbit command

Settings › API & integrations › “orbit” command › Install, then open a new terminal. Nothing else to install (no Node.js): the command runs on Orbit itself.

orbit dl https://youtu.be/… --format MP3        download (BEST, 1080p, 4K… or MP3, FLAC…)
orbit convert holiday.mov --to mp4                convert (video, audio, image, document, 3D, font, LUT)
orbit stems song.mp3 --stems 4                    split into stems (Premium)
orbit transcribe interview.mp4 --formats srt,vtt  subtitles (Premium)
orbit tts "Hello!" --voice af_heart --lang en     AI voice (Premium)
orbit image "a lighthouse at sunset"              AI image (Premium)
orbit upscale old-clip.mp4 --scale 2              AI enhancement (Premium)

orbit tools                 list the tools        orbit tools convert   a tool's parameters
orbit run <tool> --param value …                  any tool
orbit jobs · orbit job <id> --follow · orbit cancel <id>
orbit drive ls · orbit drive upload photo.jpg --share · orbit drive share <id> --days 7

Several files or links at once start one job each: orbit convert *.mov --to mp4, orbit dl link1 link2 --format MP3. A progress bar shows while the job runs. Ctrl+C cancels the job. --json prints the result as JSON (handy in scripts), and --no-wait returns the job id right away instead of waiting for the end.

Exit codes: 0 success · 1 the tool failed · 2 invalid parameter · 3 Orbit unreachable · 130 cancelled.

AI agents (MCP)

The MCP server gives Orbit's tools to your agent. You can then ask it, for example: “download this video, split the vocals from the music and put the vocals on my Drive”.

  • Claude Desktop, Cursor and other MCP clients: Copy config, then paste the block into the mcpServers section of the client's configuration.
  • Claude Code: Copy command, then run it once in a terminal.

Each Orbit tool becomes an MCP tool (orbit_download, orbit_convert, orbit_tts…), plus orbit_status, orbit_job_status, orbit_cancel_job, orbit_list_jobs, orbit_analyze_url and the Drive tools (orbit_drive_list, orbit_drive_share, orbit_drive_create_folder, orbit_drive_trash). When a job takes more than ~50 s, the agent gets a jobId and follows up with orbit_job_status.

ShareX

Settings › API & integrations › ShareX › Copy, then in ShareX: Destinations › Custom uploader settings › Import › From clipboard. Your captures go to Orbit Drive, encrypted, and the share link is copied for you. Orbit Drive must be signed in (Cloud mode) and unlocked in the app.

The HTTP API

Every response is JSON. An error always has the same shape:

{ "error": { "code": "VALIDATION_ERROR", "message": "Paramètres invalides.", "details": [{ "field": "target", "message": "obligatoire" }] } }

Error message texts are in French; rely on code, which never changes.

Code HTTP Meaning
UNAUTHORIZED 401 Missing or wrong token
FORBIDDEN 403 Request from a browser, or host refused
PREMIUM_REQUIRED 403 Tool reserved for Orbit Premium
NOT_FOUND 404 Unknown route, tool or job
CONFLICT / NOT_CANCELLABLE 409 Job already finished / tool that can't be interrupted
DRIVE_NOT_READY / DRIVE_LOCKED 409 Drive not signed in / not unlocked
VALIDATION_ERROR 422 Missing, unknown or mistyped parameter, file not found
RATE_LIMITED 429 Too many tries with a wrong token (1 min wait)

Routes

Method Route Purpose
GET /v1/health Is Orbit up? (no token)
GET /v1/info Version, Premium, Drive state, tools
GET /v1/tools · /v1/tools/{id} Tools and their JSON parameter schema
POST /v1/jobs Run a tool: { "tool": "convert", "input": { … } } → 202 + the job
GET /v1/jobs Latest jobs (?status=running&limit=20)
GET /v1/jobs/{id} Job state; ?wait=25 waits for it to finish (30 s max)
GET /v1/jobs/{id}/events Live stream (Server-Sent Events): job, progress, log, end
DELETE /v1/jobs/{id} Cancel the job
POST /v1/analyze Info about a link without downloading it: { "url": "…" }
GET /v1/drive Drive sign-in and lock state
GET /v1/drive/nodes A folder's content (?parent=<id>, ?q=name, ?page=, ?pageSize=)
POST /v1/drive/folders Create a folder: { "name": "…", "parent": "<id>" }
POST /v1/drive/files Raw file upload: ?name=capture.png&parent=<id>&share=1
POST /v1/drive/shares Share link: { "id": "…", "days": 7, "password": "…" }
DELETE /v1/drive/nodes/{id} Move to the trash (30 days)

A job goes through queued (waiting for a GPU slot), running, then succeeded, failed or cancelled. File paths are absolute and live on this PC.

orbit tools <tool> or GET /v1/tools/<tool> list every parameter of a tool.

Example (PowerShell)

$cfg = Get-Content "$env:USERPROFILE\.orbit\api.json" | ConvertFrom-Json
$h = @{ Authorization = "Bearer $($cfg.token)" }
$job = Invoke-RestMethod -Method Post -Uri "http://127.0.0.1:$($cfg.port)/v1/jobs" -Headers $h -ContentType 'application/json' `
  -Body '{"tool":"convert","input":{"inputPath":"C:\\Videos\\clip.mov","target":"mp4"}}'
do { $job = Invoke-RestMethod -Uri "http://127.0.0.1:$($cfg.port)/v1/jobs/$($job.id)?wait=25" -Headers $h } while ($job.status -in 'queued','running')
$job.result.outputPath

Good to know

  • AI tools use the same GPU queue as the tabs: an API job waits its turn if a render is already running (Simultaneous AI jobs setting in AI & Performance).
  • The Drive goes through the app, which does the encryption: your Drive stays end-to-end encrypted, and the token never leaves your PC.
  • The job list is kept in memory until Orbit closes (last 200).
